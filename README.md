# 🇬🇧 English Trainer

Простое приложение для самостоятельного изучения и практики английского языка.

## Возможности

- 📚 Практика английского языка
- 🧠 Повторение изученных слов
- 🎯 Удобный формат тренировок
- 💻 Работает на Windows

## Установка

1. Открой раздел **Releases**.
2. Скачай последнюю версию программы.
3. Запусти файл `.exe`.
